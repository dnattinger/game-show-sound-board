# Game Show Sound Board



Sound Board for playing game show sound effects



Code is saved in LabVIEW 2020.



Apply the .vipc file to install necessary dependencies from VIPM.



Game show .mp3 files provided by https://soundbuttonspro.com.



To add sound effects for another game show, add a new subfolder under "mp3s" with the name of the game show, along with .mp3 files for that show. Note that the .mp3 file names appear as the buttons in the sound board.
